# Testing

Suites run without a real L4D2 install (mock VScript peers + temp dirs),
except the Windows live gate ([WINDOWS_TESTING.md](WINDOWS_TESTING.md),
one recorded run so far) and one ignored test that needs a local Steam
install (`cargo test -p l4d2api-installer -- --ignored`; it finds the
install through the installer's own Steam discovery).

## Commands

```bash
cargo test --locked --workspace
cd sdk/python && PYTHONPATH=src python3 -m unittest discover -s tests
cd sdk/javascript && npm test
python3 scripts/gen_fixtures.py --check
bash scripts/lint_nut.sh
```

## Required matrix

| Test | Where | Expected |
|---|---|---|
| Valid connection | client suites (all SDKs) | correct heartbeat and readiness |
| Game closed | client suites | disconnected/absent, not ready |
| Game restarted | client suites | old generation rejected |
| Old command | fixtures + replay rules | never re-executed |
| Duplicate request id | client suites + `duplicate_request.txt` | no duplicate gameplay action |
| Parallel SDK clients | client suites (lock tests) | single writer enforced |
| Windows existing command file | client suites (replace test) | replacement succeeds |
| Malformed command | codec suites + fixtures | rejected, no execution |
| Unsupported capability | client suites | explicit refusal before any write |
| Partial spawn | `result_partial.txt` + VScript `FinishSpawn` | correct actual + `partial` |
| Entity limit reached | VScript `limits.nut` accounting | `ENTITY_CAP` refusal |
| Round change | `NewGeneration` resets | counters/session state reset |
| Timed-out mutation | client suites | reported ambiguous, never replayed |
| Invalid VPK | installer `rejects_arbitrary_bytes_as_vpk` | installation rejected |
| Failed upgrade | installer `failed_upgrade_preserves_previous_install` | previous install preserved |
| Quarantine restore conflict | installer `restore_never_overwrites_existing_destination` | existing destination preserved |
| Python/Rust parity | `sdk/python/tests/test_protocol.py` | shared fixtures agree |
| JavaScript/Rust parity | `sdk/javascript/tests/protocol.test.mjs` | shared fixtures agree |

Windows-only behavior is covered by Windows-native tests where the
platform demands it (atomic replace, path handling); Linux simulation is
never labeled as Windows gameplay verification.

## Fixtures

`tests/fixtures/` is generated by `scripts/gen_fixtures.py` (FNV-1a
checksums computed, not hand-written). Regenerate with the script, verify
with `--check`. The `.note` sidecars document fixtures that decode fine
but must never execute (old generation, out-of-order, duplicate).
