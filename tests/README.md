# Tests

Golden protocol records live in [`fixtures/`](fixtures/) and are generated by
[`scripts/gen_fixtures.py`](../../scripts/gen_fixtures.py) — never hand-edit
checksums:

```bash
python3 scripts/gen_fixtures.py        # regenerate
python3 scripts/gen_fixtures.py --check # CI freshness check
```

Runnable suites (no L4D2 runtime needed):

- `cargo test -p l4d2api-protocol` — codec round-trips + golden fixtures.
- `cargo test -p l4d2api-client` — fake-VScript-peer tests (handshake,
  ack, timeout-is-not-success, stale generation, duplicate/partial reads).
- `cargo test -p l4d2api-installer` — Steam discovery, lifecycle keeping
  foreign mods, escapes, Unicode paths.
- `cargo test -p l4d2api-pack` — VPK round-trip, determinism, contract
  validation, IEEE CRC-32 vector.

Live Windows validation is tracked in
[`docs/WINDOWS_TESTING.md`](../../docs/WINDOWS_TESTING.md) and is currently
**blocked** on this Linux workspace.
